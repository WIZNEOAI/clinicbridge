# Contest submission playbook

[Open Agentic Web Challenge](https://cognizant-agenticweb.devpost.com/) · [Rules](https://cognizant-agenticweb.devpost.com/rules) · [Devpost terms](https://info.devpost.com/terms)

Internal target January 4, 2027; official deadline January 11, 2027 at 16:00 UTC / 10:00 Mexico City, subject to organizer updates.

## Registration and compliance

- [ ] Entrant selects team mode and explicitly agrees to eligibility, rules and terms.
- [ ] Confirm registration. Earlier account check indicated eligible to register, not registered.
- [ ] Confirm originality, permitted AI assistance, licensing and build-period restrictions against full official rules.
- [ ] Finalize appropriate open-source license; preserve upstream notices.

## Required artifacts

- [ ] Public working agentic website URL; publicly accessible conforming network JSON, browser runtime and interaction UI.
- [ ] Text explanation of actual project functionality.
- [ ] Screenshot(s) of the working product.
- [ ] Public YouTube demo showing the project in browser, under two minutes, with actual entrant explanation (not AI-generated narration).
- [ ] If Otari used, supply account email via official submission mechanism and real feedback; do not publish private account details in the repo.
- [ ] Public source and reproducible instructions; optional reusable component link if implemented.
- [ ] Verify every URL in a clean browser and confirm model access for judging.
- [ ] Entrant explicitly approves and submits; retain confirmation.

## Judging map

| Official criterion | Evidence to prioritize |
|---|---|
| Technological Implementation | Official runtime and live peer interactions; spec validation |
| Design | Complete adaptive workflow, accessible UI, trustworthy approval |
| Potential Impact | Specific administrative problem, developer pattern, reusable component if real |
| Quality of the Idea | Open interoperability and consent-first adaptive experience |

No assumption of winning. Prize amounts and terms must be rechecked against the official site.

## Demo storyboard: 110 seconds

0–12s: problem, fictional-data disclosure. 12–30s: browser and three independent origins. 30–55s: permissioned peer reads and generated comparison. 55–80s: review, cancel, then explicit peer approval. 80–95s: actual receipt and trace. 95–110s: repository and verified contribution. Use real footage, founder voice and permitted media. Never show optional protocols that did not ship.
