# Contributing to ClinicBridge

Thanks for your interest. This is currently a planning repository. Implementation is not yet authorized in this session; wait for maintainer direction before beginning application work or importing dependencies.

Read [README](README.md), [PRD](docs/PRD-v2.md), [AGENTS.md](AGENTS.md), [plan](plan.md), and [security](SECURITY.md) first.

## Proposed workflow

1. Discuss scope in an issue or discussion; link a CB task ID in plan.md.
2. Confirm the relevant upstream version and license; keep implementation incremental and independently reviewable.
3. Open a focused branch and PR. Describe actual changes, test commands/results, evidence, security impact and remaining limitations.
4. Never treat a passing mock as real peer interoperability. Mark tests not run as not run.
5. Do not introduce new protocols, services, cost or data sources without a recorded decision.
6. Maintainer reviews before merge or deployment. Do not submit contest materials on someone else's behalf.

Use English for repository documents and technical discussion. Be respectful and constructive. No real patient information, credentials, unrelated private client code, or copyrighted assets without permission.

The proposed Apache-2.0 license is pending confirmation. Do not contribute third-party source or assume an open-source license grant before the maintainer records the decision.
